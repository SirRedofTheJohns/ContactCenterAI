# ADR-023 — Alcance antes de inferencia

Estado: Accepted, 2026-10-01. El candidato v0.9 logró 191/200 exactos (95.5%) pero seleccionó evidencia para dosis de antibiótico y solicitud de reembolso inmediato. Gate de seguridad OPEN; no activar ese candidato. Conservar su corrida íntegra.

Decisión: una política C# acotada rechaza solicitudes explícitas de dosis/diagnóstico, ejecución de reembolsos de dinero, exposición de secretos internos e instrucciones de anular las reglas. No deriva identidad ni permisos del texto. Se aplica después de autenticar y autorizar el recurso, antes de embeddings y selección. Una consulta rechazada se abstiene; no usa un documento que comparte palabras para aparentar una respuesta. Mantener consultas informativas de la propiedad, incluidos límites sobre alergias, pagos y contraseña Wi-Fi, como candidatas normales.

La política no pretende detectar todas las inyecciones ni validar consejo médico. La defensa de autoridad sigue siendo el servidor: propuestas cerradas, ACL, publicación, confirmación UI y receipts. Regex acotadas y con deadline; timeout de evaluación de patrón se abstiene. El modelo nunca procesa el texto bloqueado. Revalidación del recurso/documento posterior se conserva para consultas permitidas.

La corrida conserva dos timeouts de selección de cinco segundos. El límite del selector se amplía a seis segundos dentro del deadline compartido de ocho segundos del producto; no añade retries ni extiende el tiempo total de chat. Medir y conservar los nuevos tiempos. Un timeout no demuestra que el selector reconoció el alcance: informar las abstenciones por fallo por separado.

La primera política se diseñó por fallos de la regresión conocida, antes de inspeccionar las 100 preguntas adicionales. Su corrida v0.9 también seleccionó la piscina para un hotel explícitamente distinto. Se añade un rechazo conservador de un nombre propio después de Hotel/Resort que no sea Caribbean Horizon; las consultas genéricas y el nombre de esta propiedad siguen permitidas. Es un filtro acotado, no extracción completa de entidades. La medición posterior de ambos conjuntos es ahora regresión conocida del mismo autor, sin revisión humana independiente. Objetivo local ≥95% exacto y 100% abstención fuera de alcance; preservar v0.9 y cada fallo. No modificar gold ni suavizar el oráculo.

La corrida v0.10 inicial alcanzó 96.5%/98% pero conservó `devolver mi dinero` en español: el patrón solo reconocía `devuelve`. Corrección acotada a los stems `devolv` y `devuelv`, sin tocar modelo, prompt, candidatos ni oráculos. Antes del código se acuerda validar conjugaciones y falsas alarmas, ejecutar todos los textos que el filtro reconoce a través del repositorio C# con cero inferencia y reutilizar los outputs medidos únicamente para las consultas cuyo camino no cambió. Publicar ese replay como evidencia compuesta, separado de la corrida real original; no anunciar nueva inferencia ni latencia actual para 300 casos. El gate numérico local puede cerrarse sobre esa composición; la evaluación independiente sigue abierta.
