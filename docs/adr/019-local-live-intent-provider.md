# ADR-019 — Inferencia local con autoridad limitada

Estado: Accepted, 2026-10-01. Refinamiento compatible de FR02/14, NFR06/11/15, AC01/25/26/32. Freeze v0.6 separa diseño, integración y evaluación. No cambia los invariantes de freeze v0.1/v0.4/v0.5.

La máquina tiene Ollama 0.32.15 y qwen3-vl:latest ya descargado (digest 901cae73216286ea8c5aba8b46d307ff7188f737285ec500c795a12f05225d28, Q4_K_M). Se reutiliza para clasificar intenciones ES/EN mediante inferencia real; no descargar modelos, llamar cloud ni tocar credenciales. Ollama es un proceso auxiliar loopback. El adaptador .NET usa HTTP sin redirección/proxy y valida digest antes de cada llamada. Sin modelo aprobado/disponible, la activación falla; no se sustituye silenciosamente por otro modelo ni por el simulador.

El proveedor recibe solamente mensaje sanitizado e idioma. Devuelve una propuesta JSON cerrada con la allowlist vigente. Nunca recibe identidad, fuente privada, API keys, historial privado o autoridad de escritura. El gateway C# valida de nuevo. FAQ sigue siendo extractiva desde conocimiento gobernado, y los resultados del negocio siguen siendo plantillas respaldadas por la fuente; no se añade generación factual abierta ni recuperación vectorial en este slice. Este es un LLM real para intent/tool selection, no un chatbot de generación libre.

Modos explícitos: simulated (default reproducible) y local-llm (selección persistida para el lanzador). El UI identifica el modo actual y el provider de cada respuesta histórica. Deadline por turno sigue en ocho segundos y máximo dos attempts persistentes. Carga inicial/calentar modelo ocurre antes de activar el API y se mide aparte. Una lectura/model failure produce fallback seguro, sin confirmación implícita, replay de fuente ni cambio de propietario.

Evaluación: primero tests HTTP del adaptador y safety determinista existente. Después una corrida de los 40 casos públicos de desarrollo; guardar predicción validada, razones/counts, latencia y tokens, hashes del modelo/prompt/schema/dataset. No guardar thinking, respuestas crudas de error ni payloads privados. No cambiar el prompt a partir de estos resultados y presentarlos como holdout. Resultados deficientes se publican y bloquean la afirmación de calidad aprobada. El simulador permanece disponible como rollback explícito; no degradar permisos para mejorar un score.

Refinamiento de compatibilidad cerrado antes de adaptar el transporte productivo: el template público del modelo instalado es `{{ .Prompt }}`. Chat devolvió contenido vacío; no se leyó ni utilizó thinking. Generate/raw con delimitadores fijos y un bloque de thinking vacío obtuvo una propuesta JSON válida en 2.938 s, 297 tokens de entrada y 32 de salida. Se usa POST /api/generate, raw=true, respuesta exclusivamente del campo response. La ejecución CPU num_gpu=0/num_thread=8 evita el timeout observado en GPU. No analizar thinking como propuesta, ni exportarlo. El texto de cliente se serializa con escapes JSON antes de insertarlo; nunca se construyen roles desde él. Wrapper versionado raw-chatml-empty-think-v1 y digest exacto restringen esta compatibilidad al modelo medido.

Fuentes primarias: [generate/raw/format](https://docs.ollama.com/api/generate), [chat/format/think](https://docs.ollama.com/api/chat), [loopback y modo local](https://docs.ollama.com/faq), [runtime Windows](https://docs.ollama.com/windows). No afirmar compatibilidad de otro modelo por la del elegido.
