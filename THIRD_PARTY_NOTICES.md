# Third-party components

Model weights and runtimes are not redistributed in this source/documentation archive. BGE-M3 is provided by BAAI under MIT according to its [official model card](https://huggingface.co/BAAI/bge-m3). Ollama supplies the [pinned model distribution](https://ollama.com/library/bge-m3). Preserve vendor notices when distributing downloaded weights. The installed Qwen/Ollama, Keycloak, SQL Server Developer, .NET and NuGet components retain their own licenses and installation terms.

[SBOM and dependency evidence](docs/progress/demo-v0.7-sbom.cdx.json) covers locked NuGet components with runtime/test/spike scopes. The official advisory snapshot is time-bound and does not certify the OS, containers, model runtime or SDK. NuGet content hashes exclude signatures; the full archive hash is recorded separately. Package signature certificate/revocation verification is a distinct check.
